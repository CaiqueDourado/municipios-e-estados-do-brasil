## Conventions

- Encoding UTF-8 without BOM, comma separated, header in the first line, `\n` line endings.
- Decimal point is `.`. Booleans are `True` / `False`.
- `ibge_code` joins with any IBGE table; `siafi_code` joins with Treasury (SIAFI) data; `uf` joins `municipios.csv` to `estados.csv`.
